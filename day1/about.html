About QuickNotes

QuickNotes is a simple web app for capturing short notes the moment you think of them. It helps you keep ideas, reminders and to-dos in one place so nothing gets lost.

How to use QuickNotes

  1. Type your note into the input box.
  2. Click “Add” to save it to your list.
  3. Review your notes on the main page.
  4. Delete notes you no longer need.

Features

  • Fast note capture
  • Simple, distraction-free layout
  • Works in any modern browser

Keyboard shortcuts

Shortcut Action
Ctrl + Enter Save the current note
Esc Clear the input box
